# Security policy

The project is pre-release and has no supported released versions yet. Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** action on the repository Security tab when enabled. Do not include credentials, real asset inventories, or personal data in a public issue. If private reporting is unavailable, contact a repository maintainer through the repository's GitHub profile and request a private channel; no email contact is currently published.

Please include affected version/commit, reproduction steps using synthetic data, impact, and any suggested mitigation. Maintainers will acknowledge reports as soon as practical and coordinate disclosure after a fix is available. Scope includes local data handling, imports, graph evaluation, packaging, and the opt-in notifier. This project does not claim to be a vulnerability scanner or exploit tool.
